## What it does

`main.py` (Python 3, standard library only) writes one two-part
micro-confession to `/output/entry.txt`: a `To:` line naming who the
message was meant for, and the unsent message itself — one line,
written exactly as it was typed, with no explanation after it.

## Run it

```sh
python3 main.py
```

It writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set). `python3 main.py --check` prints the
character counts without writing anything.
